**Billing & Stripe — fully built and tested working end-to-end this session:**
- Pricing model simplified from the original plan: **flat $5/member covers everything**, including all side competitions bundled in. No more $1/side-comp or $10 bundle — Ben decided that added clunky friction that risked people not turning on the fun stuff.
- New `payments` table + `paid_member_count` and `admin_unlocked` columns on `competitions` (migration: see `add_payments_table.sql` pattern used this session).
- New `lib/billing.js` — `getMemberCoverage()` and `getMemberLockStatus()`. Key mechanic: payment covers the *earliest joiners first* (by `joined_at`). Anyone joining later, beyond the paid count, is individually "uncovered" but gets a **2-week grace period from their own join date** before tipping actually locks for them. Existing covered members are never affected by a later join. This replaced an earlier, simpler "lock everyone once Round 2 starts" idea — the per-member/grace-period version is better and is what's actually built.
- Tips page (`app/competition/[slug]/tips/page.js`) now shows an amber "heads up, X days left" banner during grace period, and a red "tips paused" banner + disables pick/confidence inputs once actually locked. Viewing everything else always stays open (soft lock only).
- `/api/stripe/create-checkout-session` (route.js) — verifies caller is the comp owner via their access token, computes `memberCount × $5`, creates a Stripe Checkout Session (promo codes enabled), stores a `pending` payment row, returns `session.url`.
- `/api/stripe/webhook` (route.js) — verifies Stripe signature, on `checkout.session.completed` marks the payment `completed` and raises `paid_member_count` (never lowers it, guards against replay).
- Settings page (`app/competition/[slug]/settings/page.js`) got a new **Billing section**: shows current members vs. paid-for count, a Pay button when behind, admin-unlocked indicator. **Owner-only visibility** (route is `/competition/[slug]/settings`, no nav link to it — direct URL only).
- **Confirmed working live**, real Stripe test payment completed, `paid_member_count` updated correctly via webhook, banner cleared. Tested with Stripe CLI (`stripe listen --forward-to localhost:3000/api/stripe/webhook`) for local webhook forwarding.
- **Not yet built:** the super-admin manual unlock UI (hardcoded to Ben's email) — was the natural next step when this session ended.
